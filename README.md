# Family Budget Calculator

A simple budgeting application calculator built using HTML, CSS and JavaScript.

# Features

- Calculate monthly income
- Track expenses
- Set savings goal
- Track investment
- View remaining balance
- Responsive Design

## Technologies

HTML
CSS3
JavaScript

## Recent Updates

The following features have been added to improve usability and user experience:

- 🌙 Dark Mode support for a modern and eye-friendly interface.
- 📊 Export Budget feature to download budget data for future reference.
- 💾 Save Report functionality to store budget reports directly within the application.
- ✅ Dynamic budget result indicators:
  - Positive budget balance is displayed in green.
  - Negative budget balance is displayed in red.
- 🧹 Clear All button to quickly reset all input fields.
